Bank Account Simulation Using Java

About the Project

A console-based banking application developed using Java as part of my CodeOrbit Tech Java Programming Internship.

Features

- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Prevent withdrawals exceeding the available balance
- Validate user inputs

Technologies Used

- Java
- Scanner Class
- Switch Statement
- ArrayList
- Do-While Loop
- Conditional Statements
- Eclipse IDE

How to Run

1. Install the Java JDK.
2. Open the project in Eclipse IDE.
3. Open "BankAccountSimulation.java".
4. Run the program.
5. Select an option from the banking menu.
